Ângulos em Retas Paralelas

⏱️ 8 min de leitura +90 XP

Quando uma reta transversal corta duas retas paralelas, formam-se 8 ângulos com relações especiais entre si.

Nomenclatura

Imagine duas retas paralelas (r e s) cortadas por uma transversal (t). Os ângulos entre as paralelas são internos, os de fora são externos.

Ângulos Correspondentes

Ficam na mesma posição relativa em cada cruzamento. São iguais.

Se um mede 60°, seu correspondente na outra paralela também mede 60°.

Ângulos Alternos Internos

Ficam entre as paralelas, em lados opostos da transversal. São iguais.

Ângulos Alternos Externos

Ficam fora das paralelas, em lados opostos. Também são iguais.

Ângulos Co-internos (Colaterais Internos)

Ficam entre as paralelas, do mesmo lado da transversal. São suplementares (somam 180°).

Resumo Visual

  • Correspondentes: mesma posição → iguais
  • Alternos (internos ou externos): lados opostos → iguais
  • Co-internos: mesmo lado, entre paralelas → somam 180°

Exemplo

Se um dos 8 ângulos mede 70°, podemos descobrir todos os outros:

  • OPV: 70°
  • Suplementar: 110°
  • Correspondente: 70°

Resultado: quatro ângulos de 70° e quatro de 110°.

Essencial para a Prova

Quando uma transversal corta duas paralelas: ângulos correspondentes são iguais, alternos internos são iguais, co-internos somam 180°.

Dúvidas Frequentes

Se ao cortar com uma transversal os ângulos correspondentes forem iguais, as retas são paralelas. É uma via de mão dupla.

As relações não valem. Ângulos correspondentes só são iguais quando as retas são paralelas. Com retas não-paralelas, cada ângulo tem seu próprio valor.

Apenas 2 valores diferentes! Se um ângulo mede α, os outros medem α ou (180° - α). Os 8 ângulos se dividem em dois grupos de 4.

Para calcular ângulos em geometria, arquitetura, engenharia e provar teoremas como 'soma dos ângulos do triângulo = 180°'.
