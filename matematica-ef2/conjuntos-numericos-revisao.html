Conjuntos Numéricos (Revisão)

⏱️ 8 min de leitura +90 XP

No 9º ano, consolidamos todos os conjuntos numéricos estudados antes e conhecemos os números irracionais e o conjunto dos reais.

Os Conjuntos

  • N (Naturais): {0, 1, 2, 3, ...} — para contar
  • Z (Inteiros): {..., -2, -1, 0, 1, 2, ...} — inclui negativos
  • Q (Racionais): todo número na forma a/b (b≠0) — inclui frações e dízimas periódicas
  • I (Irracionais): decimais infinitos não-periódicos — √2, √3, π, e...
  • R (Reais): Q ∪ I — todos os números da reta numérica

Relação de Inclusão

N ⊂ Z ⊂ Q ⊂ R

Os irracionais NÃO estão dentro de Q: I ∩ Q = ∅ (conjunto vazio).

Números Irracionais

São decimais infinitos sem padrão de repetição:

  • √2 = 1,41421356... (nunca se repete)
  • π = 3,14159265... (nunca se repete)
  • Número de Euler: e = 2,71828...

Intervalos na Reta Real

Podemos representar subconjuntos dos reais como intervalos:

  • [2, 5] = {x ∈ R | 2 ≤ x ≤ 5} (fechado)
  • (2, 5) = {x ∈ R | 2 < x < 5} (aberto)
  • [2, 5) = {x ∈ R | 2 ≤ x < 5} (misto)

Essencial para a Prova

N ⊂ Z ⊂ Q ⊂ R. Naturais (0,1,2...), Inteiros (...-2,-1,0,1,2...), Racionais (frações), Irracionais (√2, π), Reais (Q ∪ I).

Dúvidas Frequentes

Existe uma demonstração clássica por contradição (prova por absurdo). Supõe que √2 = a/b irredutível e chega a uma contradição: ambos a e b seriam pares.

Sim! Já calcularam trilhões de dígitos de π sem encontrar repetição. Foi provado irracional em 1761 por Lambert.

Sim! Os números complexos (C), que incluem a unidade imaginária i = √(-1). Você estudará no 3º EM.

Na prática, sim! Calculadoras trabalham com um número finito de dígitos, então arredondam irracionais. √2 na calculadora é uma aproximação racional.
