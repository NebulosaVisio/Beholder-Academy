Equações do 1º Grau

⏱️ 9 min de leitura +100 XP

Uma equação é uma sentença matemática com sinal de igualdade e uma incógnita (valor desconhecido, geralmente representado por x).

Exemplo Básico

x + 3 = 7 → qual valor de x torna isso verdade? x = 4

Princípio da Balança

Uma equação é como uma balança equilibrada. O que você fizer de um lado, deve fazer do outro para manter o equilíbrio.

Resolvendo Equações

Regra: isole a incógnita usando operações inversas.

Exemplo 1: 2x + 5 = 11

  1. Subtraia 5 dos dois lados: 2x = 6
  2. Divida por 2: x = 3

Exemplo 2: 3x - 7 = 2x + 4

  1. Passe 2x para a esquerda: 3x - 2x = 4 + 7
  2. Simplifique: x = 11

Exemplo 3: 4(x - 2) = 12

  1. Distribua: 4x - 8 = 12
  2. Some 8: 4x = 20
  3. Divida por 4: x = 5

Verificação

Sempre substitua o resultado na equação original para confirmar: 4(5-2) = 4×3 = 12 ✓

Traduzindo Problemas

"O dobro de um número mais 3 é igual a 15" → 2x + 3 = 15 → x = 6.

"A idade de Ana é o triplo da de Bia. Juntas, têm 28 anos" → x + 3x = 28 → 4x = 28 → x = 7 (Bia), Ana = 21.

Essencial para a Prova

Equação é uma igualdade com incógnita. Para resolver, isole o x usando operações inversas: 2x + 5 = 11 → 2x = 6 → x = 3.
