Estatística: Medidas de Dispersão

⏱️ 8 min de leitura +100 XP

No 7º ano estudamos média, moda e mediana (tendência central). Agora vamos medir o quanto os dados variam ao redor dessa tendência.

Amplitude

A = maior valor - menor valor

Ex: Notas 3, 5, 7, 8, 9 → A = 9 - 3 = 6

Simples, mas sensível a outliers.

Desvio

É a distância de cada valor até a média: d = x - x̄

Notas: 4, 6, 8. Média = 6.

Desvios: -2, 0, +2. A soma dos desvios é sempre zero!

Variância (σ²)

Média dos quadrados dos desvios:

σ² = Σ(xi - x̄)² / n

Ex: Desvios: -2, 0, +2 → Quadrados: 4, 0, 4 → σ² = 8/3 ≈ 2,67

Desvio Padrão (σ)

σ = √variância

Ex: σ = √2,67 ≈ 1,63

O desvio padrão está na mesma unidade dos dados (notas, cm, kg), por isso é mais intuitivo que a variância.

Interpretação

  • Desvio padrão pequeno: dados concentrados perto da média (consistentes)
  • Desvio padrão grande: dados espalhados (muita variação)

Exemplo Prático

Turma A: notas 7, 7, 7, 7 (σ = 0, perfeita consistência)

Turma B: notas 2, 5, 9, 12 (σ alto, muita variação)

Ambas podem ter a mesma média (7), mas comportamentos bem diferentes!

Essencial para a Prova

Dispersão mede o 'espalhamento' dos dados. Amplitude = máximo - mínimo. Variância = média dos quadrados dos desvios. Desvio padrão = √variância.

Dúvidas Frequentes

Para eliminar os sinais negativos. A soma dos desvios sempre dá zero (se cancelam). Elevando ao quadrado, todos ficam positivos e podemos calcular a média.

A variância está em unidades ao quadrado (difícil interpretar). O desvio padrão é a raiz da variância, voltando à unidade original dos dados.

Que todos os valores são iguais (nenhuma variação). Ex: {5, 5, 5, 5} tem σ = 0.

Desvio padrão! A amplitude só usa 2 valores (max e min) e é muito sensível a outliers. O desvio padrão usa todos os dados.
