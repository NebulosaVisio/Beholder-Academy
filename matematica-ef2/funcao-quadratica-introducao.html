Função Quadrática (Introdução)

⏱️ 10 min de leitura +120 XP

A função quadrática (2º grau) gera gráficos em forma de parábola — a curva dos arcos, jatos d'água e trajetórias de projéteis.

Formato

f(x) = ax² + bx + c, com a ≠ 0

A Parábola

O gráfico é uma curva simétrica chamada parábola:

  • a > 0: parábola abre para cima (forma de vale ∪) — tem ponto mínimo
  • a < 0: parábola abre para baixo (forma de montanha ∩) — tem ponto máximo

Vértice

O ponto mais alto (ou mais baixo) da parábola:

xv = -b / 2a

yv = f(xv) ou yv = -Δ / 4a

Raízes (Zeros)

Onde a parábola cruza o eixo x. Usamos Bhaskara:

  • Δ > 0: duas raízes (cruza 2 vezes)
  • Δ = 0: uma raiz (toca o eixo)
  • Δ < 0: nenhuma raiz (não toca o eixo)

Exemplo

f(x) = x² - 4x + 3

a=1, b=-4, c=3

Δ = 16 - 12 = 4 → raízes: x = (4±2)/2 → x₁=3, x₂=1

Vértice: xv = 4/2 = 2, yv = 4-8+3 = -1 → V(2, -1)

Aplicações

Trajetória de uma bola, lucro máximo de uma empresa, área máxima com perímetro fixo.

Essencial para a Prova

f(x) = ax²+bx+c. Gráfico: parábola. a>0: concavidade para cima (vale). a<0: para baixo (montanha). Vértice: xv = -b/2a. Raízes: Bhaskara.

Dúvidas Frequentes

Porque o x² faz com que valores simétricos de x (ex: 2 e -2) produzam o mesmo f(x). Essa simetria gera a forma curva.

A 'direção' da abertura da parábola. a>0: para cima (como uma tigela). a<0: para baixo (como um guarda-chuva).

É o ponto de máximo ou mínimo. Útil para otimização: lucro máximo, altura máxima de um projétil, custo mínimo.

Não! Se Δ < 0, a parábola não toca o eixo x. Ex: f(x) = x² + 1 está sempre acima do eixo x.
