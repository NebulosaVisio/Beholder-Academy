Combinação

⏱️ 7 min de leitura +200 XP

Introdução

Combinação conta de quantas formas escolher p elementos de n quando a ordem NÃO importa.

Fórmula

C(n,p) = n! / [p! · (n−p)!]

Ex: Comissão de 3 entre 10 pessoas: C(10,3) = 10!/(3!·7!) = 120

Arranjo vs Combinação

ArranjoCombinação
Ordem importaOrdem NÃO importa
A(n,p) = n!/(n−p)!C(n,p) = n!/[p!(n−p)!]
Pódio, senhaComissão, equipe

Relação: C(n,p) = A(n,p)/p!

Propriedades

  • C(n,0) = C(n,n) = 1
  • C(n,p) = C(n, n−p) (simetria)
  • C(n,1) = n

Triângulo de Pascal

Cada número é a soma dos dois acima. A linha n contém C(n,0), C(n,1), ..., C(n,n).

Resumo

  • ✅ C(n,p) = n!/[p!(n−p)!]
  • ✅ Ordem NÃO importa
  • ⚠️ Dica: 'escolher', 'comissão', 'equipe' → combinação!

Curiosidade

A Mega-Sena pede 6 números de 60: C(60,6) = 50.063.860 combinações. Sua chance de acertar é de 1 em 50 milhões!

Essencial para a Prova

C(n,p) = n!/[p!·(n−p)!]. Ordem NÃO importa: {A,B,C}={C,B,A}. C(n,p)=C(n,n−p). C(n,0)=C(n,n)=1. Triângulo de Pascal: cada número = soma dos dois acima. C(n,p) = A(n,p)/p!.

Dúvidas Frequentes

Combinação: ordem NÃO importa (equipe, comissão, subconjunto). Arranjo: ordem IMPORTA (pódio, senha, ranking).

Sim! Escolher p para incluir = escolher (n−p) para excluir. C(10,3) = C(10,7) = 120.

Cada linha n tem os valores C(n,0) a C(n,n). Cada número = soma dos dois acima. É útil para binômio de Newton.
