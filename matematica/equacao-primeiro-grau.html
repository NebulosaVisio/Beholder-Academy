Equação do 1º Grau

Espaço Publicitário

A equação do primeiro grau é uma sentença matemática com uma incógnita elevada ao expoente 1. Sua forma geral é: ax + b = 0, onde a ≠ 0.

Como resolver?

O objetivo é isolar a incógnita (x). Para isso, siga 2 passos:

Passo 1: Mova o termo independente

Passe o número "solto" (sem x) para o outro lado da igualdade, invertendo o sinal.

Exemplo: 2x + 6 = 0 → 2x = -6

Espaço Publicitário

Passo 2: Divida pelo coeficiente

Divida ambos os lados pelo número que multiplica o x.

Exemplo: 2x = -6 → x = -6 ÷ 2 → x = -3

Mais exemplos

  • 5x - 15 = 0 → 5x = 15 → x = 3
  • 3x + 9 = 0 → 3x = -9 → x = -3
  • -4x + 8 = 0 → -4x = -8 → x = 2

Essencial para a Prova

  • Forma geral: ax + b = 0 (a ≠ 0)
  • Isolar o x: passe o b para o outro lado, divida por a
  • Fórmula direta: x = -b/a
  • Sempre verifique substituindo x na equação original

Perguntas Frequentes

É uma sentença matemática com uma incógnita (geralmente x) elevada ao expoente 1. Forma geral: ax + b = 0, onde a ≠ 0.
Isole a incógnita: passe o termo independente para o outro lado invertendo o sinal, depois divida pelo coeficiente de x. Exemplo: 2x + 6 = 0 → 2x = -6 → x = -3.
