Estatística: Medidas de Tendência Central

⏱️ 7 min de leitura +200 XP

Introdução

As medidas de tendência central resumem um conjunto de dados em um valor representativo. São essenciais para interpretar gráficos e tabelas no ENEM.

Média Aritmética

x̄ = (x₁+x₂+...+xₙ)/n

Ex: {2,4,6,8,10} → x̄ = 30/5 = 6

Média Ponderada

x̄ₚ = Σ(xᵢ·wᵢ) / Σwᵢ

Ex: Prova 1 (peso 3) = 7, Prova 2 (peso 2) = 9: x̄ = (7·3+9·2)/(3+2) = 39/5 = 7,8

Mediana

Valor central dos dados ORDENADOS:

  • n ímpar: valor do meio
  • n par: média dos 2 do meio

Moda

Valor mais frequente. Pode ser: amodal (sem moda), unimodal, bimodal ou multimodal.

Resumo

  • ✅ Média: soma/n (afetada por outliers)
  • ✅ Mediana: resistente a outliers
  • ⚠️ ENEM: interpretar gráficos + calcular medidas!

Curiosidade

"Se Bill Gates entrar numa sala com 30 pessoas, a média de renda vai para milhões, mas a mediana quase não muda." Isso mostra por que a mediana é melhor para descrever renda — é resistente a valores extremos!

Essencial para a Prova

Média aritmética: x̄ = Σxᵢ/n. Média ponderada: Σ(xᵢ·wᵢ)/Σwᵢ. Mediana: valor central (n ímpar) ou média dos 2 centrais (n par) dos dados ORDENADOS. Moda: valor mais frequente (pode ser amodal, unimodal, bimodal). Média é sensível a outliers; mediana não.

Dúvidas Frequentes

Média: dados sem outliers, distribuição simétrica. Mediana: dados com outliers ou distribuição assimétrica (como renda). A mediana é mais 'robusta'.

É bimodal (2 valores com mesma frequência máxima). Pode ter mais (multimodal) ou nenhuma (amodal).

Some as frequências para achar n, encontre a posição (n+1)/2, acumule frequências até ultrapassar essa posição.

Sim! O ENEM usa média ponderada no SiSU (cada prova tem peso diferente por curso). A fórmula é Σ(nota·peso)/Σpesos.
