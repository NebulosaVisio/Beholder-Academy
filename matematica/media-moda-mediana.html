Média, Moda e Mediana

⏱️ 8 min de leitura +80 XP

As medidas de tendência central resumem um conjunto de dados em um único valor representativo. As três principais são: média, moda e mediana.

Média Aritmética

Média = soma de todos os valores ÷ quantidade de valores

Ex: Notas: 7, 8, 6, 9, 5 → Média = (7+8+6+9+5)/5 = 35/5 = 7,0

A média é influenciada por valores extremos. Se uma nota fosse 0, a média cairia bastante.

Moda

É o valor que mais aparece (o mais frequente).

Ex: Notas: 7, 8, 7, 9, 7 → Moda = 7 (aparece 3 vezes)

Um conjunto pode ser:

  • Unimodal: uma moda
  • Bimodal: duas modas
  • Amodal: sem moda (todos com mesma frequência)

Mediana

É o valor central quando os dados estão em ordem.

Quantidade ímpar: o valor do meio.

Ex: 3, 5, 7, 9, 11 → Mediana = 7

Quantidade par: média dos dois do meio.

Ex: 3, 5, 7, 9 → Mediana = (5+7)/2 = 6

Quando Usar Cada Uma?

  • Média: quando os valores são equilibrados, sem extremos
  • Mediana: quando há valores muito altos ou baixos (salários, preços)
  • Moda: para dados categóricos (cor favorita, tamanho de roupa)

Exemplo Prático

Salários de uma empresa: R$ 2.000, 2.500, 3.000, 3.000, 50.000

Média: R$ 12.100 (distorcida pelo CEO). Mediana: R$ 3.000 (mais realista). Moda: R$ 3.000.

Essencial para a Prova

Média: soma dos valores ÷ quantidade. Moda: valor mais frequente. Mediana: valor central quando ordenados. Cada uma serve para diferentes situações.
