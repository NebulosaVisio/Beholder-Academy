Números Racionais

⏱️ 8 min de leitura +90 XP

Os números racionais formam o conjunto Q — todos os números que podem ser escritos na forma a/b, onde a e b são inteiros e b ≠ 0.

Quem Pertence a Q?

  • Inteiros: 5 = 5/1, -3 = -3/1, 0 = 0/1 ✓
  • Frações: 2/3, -7/4 ✓
  • Decimais finitos: 0,75 = 3/4 ✓
  • Dízimas periódicas: 0,333... = 1/3 ✓

Então: N ⊂ Z ⊂ Q (naturais dentro dos inteiros, dentro dos racionais).

Racionais na Reta Numérica

Entre quaisquer dois inteiros existem infinitos racionais. Entre 0 e 1: 1/2, 1/3, 1/4, 2/3, 3/4...

Operações com Racionais

As mesmas regras de frações e inteiros se combinam:

Adição: -2/3 + 5/6 → MMC(3,6)=6 → -4/6 + 5/6 = 1/6

Multiplicação: -3/4 × 2/5 = -6/20 = -3/10

Divisão: -2/3 ÷ 4/7 = -2/3 × 7/4 = -14/12 = -7/6

Dízima Periódica → Fração (Geratriz)

Para transformar 0,333... em fração:

  1. x = 0,333...
  2. 10x = 3,333...
  3. 10x - x = 3 → 9x = 3 → x = 3/9 = 1/3

Comparação de Racionais

Para comparar, iguale os denominadores ou converta para decimal.

Ex: 2/5 vs 3/8 → 16/40 vs 15/40 → 2/5 > 3/8

Essencial para a Prova

Racionais (Q) são todos os números que podem ser escritos como fração a/b com b≠0. Inclui inteiros, decimais finitos e dízimas periódicas.
