Progressão Aritmética (PA)

⏱️ 8 min de leitura +100 XP

Introdução

A Progressão Aritmética (PA) é uma sequência numérica onde a diferença entre termos consecutivos é sempre constante. Essa constante é chamada razão (r).

Razão

r = aₙ₊₁ − aₙ

Ex: (2, 5, 8, 11, ...) → r = 5−2 = 3

Termo Geral

aₙ = a₁ + (n−1)·r

Ex: a₁=2, r=3 → a₁₀ = 2 + 9·3 = 2 + 27 = 29

Soma dos Termos

Sₙ = n·(a₁ + aₙ)/2

Ex: Soma de 1 a 100: S₁₀₀ = 100·(1+100)/2 = 100·50.5 = 5050

Classificação

RazãoTipoExemplo
r > 0Crescente(2, 5, 8, 11...)
r < 0Decrescente(10, 7, 4, 1...)
r = 0Constante(5, 5, 5, 5...)

Propriedade do Termo Médio

Todo termo é a média aritmética dos seus vizinhos: aₙ = (aₙ₋₁ + aₙ₊₁)/2

Resumo

  • ✅ aₙ = a₁ + (n−1)·r
  • ✅ Sₙ = n·(a₁+aₙ)/2
  • ⚠️ Gauss somou 1 a 100 em segundos usando essa fórmula!

Curiosidade

Conta a lenda que Carl Friedrich Gauss, aos 7 anos, calculou a soma de 1 a 100 mentalmente. Enquanto seus colegas somavam um a um, Gauss percebeu: 1+100=101, 2+99=101, ..., 50+51=101 → 50×101 = 5050!

Essencial para a Prova

PA: diferença constante entre termos consecutivos (razão r). Termo geral: aₙ = a₁ + (n−1)·r. Soma: Sₙ = n·(a₁+aₙ)/2. r>0 → crescente. r<0 → decrescente. r=0 → constante. Propriedade: qualquer termo é a média aritmética dos vizinhos (aₙ = (aₙ₋₁+aₙ₊₁)/2).

Dúvidas Frequentes

Subtraia qualquer termo pelo anterior: r = aₙ₊₁ − aₙ. Em (3,7,11,15,...), r = 7−3 = 4. Se a diferença não for constante, NÃO é PA.

Use aₙ = a₁ + (n−1)·r. Ex: a₁=3, r=4, n=50 → a₅₀ = 3 + 49·4 = 3 + 196 = 199.

Sₙ = n·(a₁+aₙ)/2. Você precisa saber o primeiro, o último e a quantidade de termos. Se não sabe o último, calcule com o termo geral primeiro.

Sim! Uma PA pode ser vista como uma função afim f(n)=a₁+(n−1)·r aplicada a n∈ℕ. O gráfico são pontos sobre uma reta.
