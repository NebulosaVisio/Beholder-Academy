Semântica: Polissemia, Homonímia, Paronímia

⏱️ 8 min de leitura +100 XP

Introdução

A semântica estuda os significados das palavras e as relações entre eles. Entender polissemia, homonímia e paronímia é fundamental para interpretação textual e para evitar erros de vocabulário em redações.

Polissemia

Uma mesma palavra com vários significados relacionados:

  • "Manga": fruta / parte da camisa (mesma origem: forma alongada)
  • "Cabo": posto militar / acidente geográfico / alça de ferramenta
  • "Ponto": nota / lugar / costura / parada de ônibus

Homonímia

Palavras iguais na forma mas com significados sem relação:

TipoDefiniçãoExemplo
HomófonosMesmo som, grafia diferentesessão (cinema) / seção (parte) / cessão (ceder)
HomógrafosMesma grafia, som diferentecolher (verbo) / colher (substantivo)
PerfeitosMesma grafia e sommanga (fruta) / manga (camisa)

Paronímia

Palavras parecidas na grafia/som, mas com significados diferentes:

ParônimoSignificado
comprimento / cumprimentoextensão / saudação
emigrar / imigrarsair do país / entrar no país
ratificar / retificarconfirmar / corrigir
tráfego / tráficotrânsito / comércio ilegal
descrição / discriçãoato de descrever / ser discreto
infligir / infringiraplicar (pena) / violar (lei)

Sinonímia e Antonímia

  • Sinônimos: palavras com sentido próximo (bonito/belo, casa/lar, feliz/contente)
  • Antônimos: palavras com sentido oposto (bonito/feio, grande/pequeno, amor/ódio)

💡 Sinônimos perfeitos são raros — quase sempre há uma nuance de diferença.

Resumo e Dicas para a Prova

  • ✅ Polissemia: vários sentidos de uma mesma palavra.
  • ✅ Homonímia: palavras iguais, sentidos sem relação.
  • ✅ Paronímia: palavras parecidas, sentidos diferentes.
  • ✅ Memorize: sessão/seção/cessão, comprimento/cumprimento, ratificar/retificar.
  • ⚠️ No ENEM: questões de semântica pedem o sentido da palavra no contexto.

Curiosidade

A palavra "manga" é um dos exemplos mais famosos de homonímia/polissemia. Ela pode significar a fruta (do malaio mangga), a parte da camisa (do latim manica) e até uma armadilha para peixes! São origens etimológicas totalmente diferentes que coincidiram na mesma forma.

Essencial para a Prova

Polissemia: UMA palavra com vários sentidos (''manga'' de camisa e fruta). Homonímia: palavras iguais com significados sem relação. Homófonos: mesmo som, grafia diferente (sessão/seção/cessão). Homógrafos: mesma grafia, som diferente (colher verbo/substantivo). Parônimos: parecidos mas diferentes (comprimento/cumprimento, emigrar/imigrar, ratificar/retificar). Sinônimos: sentido próximo. Antônimos: sentido oposto.

Dúvidas Frequentes

Na polissemia, uma mesma palavra tem vários sentidos RELACIONADOS (cabo: militar, geográfico, ferramenta — todos ligados a 'extremidade'). Na homonímia, os sentidos NÃO têm relação (manga fruta ≠ manga camisa — origens diferentes).

São palavras com o mesmo som mas grafia diferente: sessão (reunião, cinema), seção (divisão, parte) e cessão (ato de ceder). Acertar a grafia é cobrado em provas de ortografia.

Ratificar = confirmar, validar: 'O juiz ratificou a sentença'. Retificar = corrigir: 'Preciso retificar minha declaração'. São parônimos — palavras parecidas com sentidos diferentes.

São muito raros. A maioria dos sinônimos tem nuances diferentes: 'casa' e 'lar' (lar tem valor afetivo), 'morrer' e 'falecer' (falecer é eufemismo). O contexto determina qual sinônimo é mais adequado.
